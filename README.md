# DicksonGrafiks — Visuals That Speaks
**Founder & Creative Director:** Goodness N. Dickson

High-end creative portfolio featuring 3D interactive WebGL artboards, global network sphere, curated showcase, cinematic video edits, and photo retouching collection.

---

## Instant Deployment on Netlify (Option A: 30 Seconds)
1. In this packager, click **Download Project ZIP**.
2. Extract `dicksongrafiks-portfolio.zip` on your machine.
3. Open https://app.netlify.com/drop in your browser.
4. Drag and drop the `dist` folder directly onto the upload zone.
5. Netlify will publish your site immediately with global CDN and HTTPS!

---

## Full Build from Source (Option B: Git & Vite)
```bash
# 1. Install dependencies
npm install

# 2. Start local dev server
npm run dev

# 3. Build for production
npm run build
```

Pushing this repo to GitHub will automatically trigger Netlify continuous deployment using the included netlify.toml configuration.
